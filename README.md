# Atacama Run Companion

A phone web app for preparing for and running the ~500 km Iquique → San Pedro de Atacama relay.

- **Today** – countdown, today's session, mood check-in, altitude profile
- **Prep** – 16-day plan, training log, packing list
- **Mind** – box breathing, rough-patch protocol, mantras, visualization
- **Race** – race clock, leg timer/log, between-leg recovery, fuel tracking, safety
- **Stories** – generates 1080×1920 Instagram Story images from your data + content plan

Single `index.html`, no build step. Data is stored on the device (localStorage) — use "Back up data" in Settings.
